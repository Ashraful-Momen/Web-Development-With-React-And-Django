# CSS Responsive Design & Media Query - শর্ট নোট (সহজ উদাহরণসহ)

---

# Responsive Design কী?

**Responsive Website** হলো এমন Website যা **Mobile, Tablet এবং Desktop**-এ সুন্দরভাবে দেখা যায়।

**Example**

```text
Desktop  → 100%
Tablet   → 50%
Mobile   → 100%
```

একই Website বিভিন্ন Device অনুযায়ী Layout পরিবর্তন করে।

---

# Viewport (খুব গুরুত্বপূর্ণ)

```html
<meta name="viewport"
content="width=device-width, initial-scale=1.0">
```

**কাজ**

* Website-কে Mobile Friendly করে।
* Screen অনুযায়ী Zoom/Width ঠিক রাখে।

---

# Media Query

## Syntax

```css
@media only screen and (condition){

}
```

**মানে**

যদি Condition সত্য হয় তাহলে ভিতরের CSS কাজ করবে।

---

# Mobile Responsive

```css
@media only screen and (min-width:320px)
and (max-width:760px){

}
```

**মানে**

320px → 760px Screen হলে এই CSS চলবে।

**Shortcut**

```text
320px -------- 760px
     Mobile
```

---

# Tablet Responsive

```css
@media only screen and (min-width:761px)
and (max-width:1200px){

}
```

**মানে**

761px → 1200px হলে Tablet Layout হবে।

---

# Desktop

```css
1201px+
```

Desktop-এর জন্য আলাদা Media Query না দিলেও Default CSS কাজ করবে।

---

# Width পরিবর্তন

## Desktop

```css
.header{
    width:30%;
}

.menu{
    width:70%;
}
```

---

## Mobile

```css
@media(...){

.header{
    width:100%;
}

.menu{
    width:100%;
}

}
```

**ব্যাখ্যা**

সব Element এক লাইনে থাকবে।

```
Header
Menu
Content
Footer
```

---

## Tablet

```css
@media(...){

.header{
    width:50%;
}

.menu{
    width:50%;
}

}
```

**ব্যাখ্যা**

দুইটি Box পাশাপাশি থাকবে।

```
Header | Menu
```

# Grid System (12 Column)

Responsive Website-এর জন্য সাধারণত **12 Column Grid** ব্যবহার করা হয়।

```text
12 Column = 100%
```

---

## Column Formula

| Class  | Width  |
| ------ | ------ |
| col_1  | 8.33%  |
| col_2  | 16.66% |
| col_3  | 25%    |
| col_4  | 33.33% |
| col_5  | 41.66% |
| col_6  | 50%    |
| col_7  | 58.33% |
| col_8  | 66.66% |
| col_9  | 75%    |
| col_10 | 83.33% |
| col_11 | 91.66% |
| col_12 | 100%   |

---

## Example

```html
<div class="col_6"></div>
<div class="col_6"></div>
```

Output

```
50% | 50%
```

---

```html
<div class="col_4"></div>
<div class="col_4"></div>
<div class="col_4"></div>
```

Output

```
33% | 33% | 33%
```

# Float

```css
float:left;
```

**কাজ**

সব Box পাশাপাশি বসায়।

---

# Clear Float

```css
.row::after{
    content:"";
    clear:both;
    display:block;
}
```

**কাজ**

Float শেষ করে Parent-এর Height ঠিক রাখে।

---

# Universal Selector

```css
*{
    box-sizing:border-box;
}
```

**কাজ**

Padding + Border যোগ হলেও Width নষ্ট হয় না।

---

# Attribute Selector

```css
[class*="col_"]{
    float:left;
}
```

**মানে**

যে Class-এর মধ্যে `col_` থাকবে, সবগুলোর উপর CSS প্রয়োগ হবে।

Example

```
col_1 ✔
col_2 ✔
col_12 ✔
```

# Responsive Rules

### Mobile

```css
@media only screen
and (min-width:320px)
and (max-width:760px){

[class*="col_"]{
    width:100%;
}

}
```

👉 সব Box **100% Width** হবে।

---

### Tablet

```css
@media only screen
and (min-width:761px)
and (max-width:1200px){

[class*="col_"]{
    width:50%;
}

}
```

👉 সব Box **50% Width** হবে।

---

### Desktop

```css
.col_4{
    width:33.33%;
}

.col_6{
    width:50%;
}

.col_12{
    width:100%;
}
```

👉 Default Layout থাকবে।

# Interview Shortcut

| Code                    | কাজ                      |
| ----------------------- | ------------------------ |
| `@media`                | Responsive CSS           |
| `320-760px`             | Mobile                   |
| `761-1200px`            | Tablet                   |
| `1201px+`               | Desktop                  |
| `width:100%`            | Full Width               |
| `width:50%`             | Half Width               |
| `float:left`            | পাশাপাশি বসায়           |
| `clear:both`            | Float শেষ করে            |
| `margin:auto`           | Center                   |
| `box-sizing:border-box` | Width ঠিক রাখে           |
| `text-decoration:none`  | Underline Remove         |
| `border-radius`         | Corner গোল               |
| `[class*="col_"]`       | সব `col_` Class নির্বাচন |

# Golden Rules ⭐

```text
Responsive = Mobile + Tablet + Desktop

Desktop → Default CSS

Mobile → width:100%

Tablet → width:50%

float:left → পাশাপাশি

clear:both → Float Clear

container → Website Center

12 Columns = 100%

col_6 = 50%

col_4 = 33.33%

col_12 = 100%

Viewport Meta Tag ছাড়া Responsive Design সম্পূর্ণ হয় না।
```
