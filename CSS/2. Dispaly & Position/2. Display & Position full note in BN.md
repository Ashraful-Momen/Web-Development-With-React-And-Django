# CSS Display & Position - শর্ট নোট (সহজ উদাহরণসহ)

---

# ১. `display`

## `display: block`

```css
div{
    display:block;
}
```

**বৈশিষ্ট্য**

* পুরো Width দখল করে।
* `height` ও `width` কাজ করে।
* নতুন লাইনে শুরু হয়।

**Example**

```html
<div>One</div>
<div>Two</div>
```

**Output**

```
One
Two
```

---

## `display: inline`

```css
span{
    display:inline;
}
```

**বৈশিষ্ট্য**

* যতটুকু Content ততটুকু জায়গা নেয়।
* `height` ও `width` কাজ করে না।
* একই লাইনে থাকে।

**Example**

```html
<span>Hello</span>
<span>World</span>
```

**Output**

```
Hello World
```

---

## `display: inline-block`

```css
button{
    display:inline-block;
    width:120px;
    height:40px;
}
```

**বৈশিষ্ট্য**

* একই লাইনে থাকে।
* `height` ও `width` ব্যবহার করা যায়।

---

## `display: none`

```css
div{
    display:none;
}
```

**বৈশিষ্ট্য**

* Element সম্পূর্ণ Hide হয়ে যায়।
* Page-এ কোন Space নেয় না।

---

# Position

## ১. `position: static`

```css
div{
    position:static;
}
```

**বৈশিষ্ট্য**

* Default Position।
* `top`, `left`, `right`, `bottom` কাজ করে না।

---

## ২. `position: relative`

```css
.box{
    position:relative;
    top:20px;
    left:30px;
}
```

**বৈশিষ্ট্য**

* নিজের Original Position থেকে Move হয়।
* নিজের জন্য Parent Reference তৈরি করে।

---

## ৩. `position: absolute`

```css
.parent{
    position:relative;
}

.child{
    position:absolute;
    top:20px;
    left:40px;
}
```

```html
<div class="parent">
    <div class="child"></div>
</div>
```

**বৈশিষ্ট্য**

* Parent (`position: relative`) অনুযায়ী Position নেয়।
* Parent না থাকলে পুরো Page (`body`) অনুযায়ী Position নেয়।

**মনে রাখুন**

```
Parent  → position: relative
Child   → position: absolute
```

---

## ৪. `position: fixed`

```css
.menu{
    position:fixed;
    top:0;
}
```

**বৈশিষ্ট্য**

* Screen-এ Fix থাকে।
* Scroll করলেও নড়ে না।

**ব্যবহার**

* Navbar
* Chat Button
* Back To Top Button

---

## ৫. `position: sticky`

```css
.header{
    position:sticky;
    top:0;
}
```

**বৈশিষ্ট্য**

* Scroll করার আগে Normal থাকে।
* নির্দিষ্ট Position-এ পৌঁছালে Fixed হয়ে যায়।

# Position Property

## `top`

```css
top:20px;
```

---

## `left`

```css
left:50px;
```

বাম থেকে ৫০px।

---

## `right`

```css
right:30px;
```

ডান থেকে ৩০px।

---

## `bottom`

```css
bottom:10px;
```

নিচ থেকে ১০px।

# Float

## `float:left`

```css
img{
    float:left;
}
```

Element বাম পাশে চলে যায়।

---

## `float:right`

```css
img{
    float:right;
}
```

Element ডান পাশে চলে যায়।

---

## `float:none`

```css
float:none;
```

Default অবস্থায় ফিরে আসে।

---

# Clear

## `clear:left`

```css
clear:left;
```

Left Float Remove করে।

---

## `clear:right`

```css
clear:right;
```

Right Float Remove করে।

---

## `clear:both`

```css
clear:both;
```

Left এবং Right দুইটিই Clear করে।

# Z-Index

```css
.box1{
    z-index:1;
}

.box2{
    z-index:10;
}
```

**বৈশিষ্ট্য**

* বেশি `z-index` ⇒ সামনে থাকবে।
* কম `z-index` ⇒ পিছনে থাকবে।

```
z-index:1
     ↑
z-index:5
     ↑
z-index:100
```

---

## Negative Z-Index

```css
background{
    z-index:-1;
}
```

Element অন্য সব Element-এর পিছনে চলে যায়।

---

# Example

```css
.parent{
    position:relative;
    width:300px;
    height:300px;
    background:gray;
}

.child{
    position:absolute;
    top:20px;
    left:40px;
    width:100px;
    height:100px;
    background:red;
}
```

```html
<div class="parent">
    <div class="child"></div>
</div>
```

**ব্যাখ্যা**

* Parent → `relative`
* Child → `absolute`
* Child Parent-এর ভিতরে `top:20px` এবং `left:40px` অবস্থানে থাকবে।

# Interview Shortcut

| Property       | মনে রাখার সহজ উপায়                      |
| -------------- | ---------------------------------------- |
| `block`        | পুরো লাইন দখল করে                        |
| `inline`       | Height/Width কাজ করে না                  |
| `inline-block` | Height/Width কাজ করে + একই লাইনে থাকে    |
| `none`         | সম্পূর্ণ Hide                            |
| `static`       | Default Position                         |
| `relative`     | নিজের জায়গা থেকে Move + Parent তৈরি করে |
| `absolute`     | Parent অনুযায়ী Move                     |
| `fixed`        | Screen-এ সবসময় Fix                      |
| `sticky`       | Scroll করলে Fix হয়                      |
| `float:left`   | বামে যায়                                |
| `float:right`  | ডানে যায়                                |
| `clear`        | Float Remove করে                         |
| `z-index`      | Layer Control (বেশি Value = সামনে)       |
| `top`          | উপর থেকে দূরত্ব                          |
| `left`         | বাম থেকে দূরত্ব                          |
| `right`        | ডান থেকে দূরত্ব                          |
| `bottom`       | নিচ থেকে দূরত্ব                          |

## মনে রাখার Golden Rule

```
display → Element কিভাবে দেখাবে

position → Element কোথায় থাকবে

relative → Parent

absolute → Child

fixed → Screen Fixed

sticky → Scroll করলে Fixed

z-index → কে সামনে থাকবে
```
