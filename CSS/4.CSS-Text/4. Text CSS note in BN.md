# CSS Text & Shadow - শর্ট নোট (সহজ উদাহরণসহ)

---

# CSS Text Property

CSS Text Property ব্যবহার করা হয় **Text-এর Style, Position এবং Decoration** পরিবর্তনের জন্য।

---

# ১. `text-decoration`

## Syntax

```css
text-decoration:none;
```

**কাজ**

Text-এর Underline, Overline, Line-through Remove বা Add করে।

### Example

```css
a{
    text-decoration:none;
}
```

**Output**

```text
Home
```

👉 Link-এর Underline থাকবে না।

---

### Line Through

```css
p{
    text-decoration:line-through;
}
```

**Output**

```text
~~Old Price 500৳~~
```

👉 মাঝখানে Line চলে আসে।

---

### Underline

```css
text-decoration:underline;
```

---

### Overline

```css
text-decoration:overline;
```

---

# ২. `text-align`

## Left

```css
text-align:left;
```

Default Alignment।

---

## Center

```css
text-align:center;
```

Text মাঝখানে যাবে।

---

## Right

```css
text-align:right;
```

Text ডান পাশে যাবে।

---

## Justify

```css
text-align:justify;
```

**কাজ**

Text দুই পাশ সমান করে সাজায়।

Example

```text
This is a long paragraph...
```

Before

```text
Hello everyone
I love CSS
```

After Justify

```text
Hello everyone I love CSS
looks properly aligned.
```

👉 সাধারণত Paragraph-এর জন্য ব্যবহার করা হয়।

---

# ৩. `text-transform`

Text-এর Letter পরিবর্তন করে।

---

## Uppercase

```css
text-transform:uppercase;
```

Output

```text
HELLO WORLD
```

---

## Lowercase

```css
text-transform:lowercase;
```

Output

```text
hello world
```

---

## Capitalize

```css
text-transform:capitalize;
```

Output

```text
Hello World
```

👉 প্রতিটি Word-এর প্রথম Letter বড় হবে।

---

# ৪. `text-indent`

```css
text-indent:50px;
```

**কাজ**

Paragraph-এর প্রথম Line ভিতর থেকে শুরু হয়।

Example

Before

```text
Hello everyone...
```

After

```text
      Hello everyone...
```

👉 সাধারণত Paragraph-এর শুরুতে Space দেওয়ার জন্য।

---

# ৫. `word-spacing`

```css
word-spacing:20px;
```

**কাজ**

Word-এর মাঝে Gap বাড়ায়।

Before

```text
I Love Bangladesh
```

After

```text
I     Love     Bangladesh
```

---

# ৬. `letter-spacing` ⭐

```css
letter-spacing:5px;
```

**কাজ**

Letter-এর মাঝে Gap বাড়ায়।

Before

```text
HELLO
```

After

```text
H E L L O
```

---

# Text Shadow

## Syntax

```css
text-shadow:X Y Blur Color;
```

---

## Example

```css
text-shadow:2px 3px 5px green;
```

### Meaning

```text
2px  → Right
3px  → Down
5px  → Blur
green → Shadow Color
```

---

### Output

```text
Hello
   ↘ Shadow
```

আরেকটি Example

```css
h1{
    text-shadow:3px 3px 4px red;
}
```

---

# Box Shadow

## Syntax

```css
box-shadow:X Y Blur Color;
```

---

## Example

```css
box-shadow:2px 3px 5px blue;
```

### Meaning

```text
2px → Right

3px → Down

5px → Blur

Blue → Shadow Color
```

---

### Example

```css
div{
    width:200px;
    height:100px;
    background:red;

    box-shadow:5px 5px 10px gray;
}
```

👉 পুরো Box-এর চারপাশে Shadow তৈরি হবে।

---

# Difference

## Text Shadow

```css
text-shadow:2px 2px 5px red;
```

👉 শুধু **Text-এর Shadow**।

---

## Box Shadow

```css
box-shadow:2px 2px 5px blue;
```

👉 পুরো **Box-এর Shadow**।

---

# Quick Example

```css
h1{
    text-align:center;
    text-transform:uppercase;
    text-decoration:underline;
    text-shadow:2px 2px 4px gray;
}

div{
    width:200px;
    height:100px;
    background:orange;
    box-shadow:5px 5px 10px black;
}
```

# Golden Rules ⭐

```text
text-decoration → Underline Remove/Add

text-align → Text Position

text-transform → Upper/Lower/Capitalize

text-indent → প্রথম Line ভিতরে

word-spacing → Word Gap

letter-spacing → Letter Gap

text-shadow → শুধু Text-এর Shadow

box-shadow → পুরো Box-এর Shadow

Shadow Syntax:

X → Left/Right

Y → Up/Down

Blur → Shadow Softness

Color → Shadow Color
```
