আমি এটাকে আরও সহজভাবে সাজিয়ে দিলাম, যাতে ১–২ মিনিটে রিভিশন করা যায়।

# CSS Selector - শর্ট নোট (সহজ উদাহরণসহ)

## ১. Element Selector

**কাজ:** নির্দিষ্ট Tag নির্বাচন করে।

```css
div{
    background: red;
}
```

**ব্যাখ্যা:** সব `div` এর Background লাল হবে।

---

## ২. Class Selector (`.`)

**কাজ:** একাধিক Element-এ একই Style ব্যবহার করা যায়।

```html
<p class="title">Hello</p>
<h1 class="title">Welcome</h1>
```

```css
.title{
    color: blue;
}
```

**ব্যাখ্যা:** `title` Class থাকা সব Element নীল হবে।

---

## ৩. ID Selector (`#`)

**কাজ:** শুধুমাত্র একটি Unique Element নির্বাচন করে।

```html
<h1 id="header">Welcome</h1>
```

```css
#header{
    color: green;
}
```

**ব্যাখ্যা:** `header` ID শুধুমাত্র একবার ব্যবহার করা উচিত।

---

## ৪. Multiple Selector (`,`)

**কাজ:** একাধিক Element-এ একই Style।

```css
h1,p{
    color:red;
}
```

**ব্যাখ্যা:** সব `h1` এবং `p` লাল হবে।

---

# Combination Selector

## ৫. Descendant Selector (Space)

```css
div p{
    color:red;
}
```

**মানে:** `div` এর ভিতরের সব `p` নির্বাচন করবে।

```html
<div>
    <p>Hello</p>
</div>
```

---

## ৬. Child Selector (`>`)

```css
div > p{
    color:blue;
}
```

**মানে:** শুধুমাত্র `div` এর Direct Child `p` নির্বাচন করবে।

```html
<div>
    <p>Select হবে</p>

    <section>
        <p>Select হবে না</p>
    </section>
</div>
```

---

## ৭. Adjacent Selector (`+`)

```css
h1+p{
    color:red;
}
```

**মানে:** `h1` এর পরের প্রথম `p` নির্বাচন করবে।

```html
<h1>Title</h1>
<p>Select হবে</p>
<p>Select হবে না</p>
```

---

## ৮. General Sibling (`~`)

```css
h1~p{
    color:blue;
}
```

**মানে:** `h1` এর পরের সব `p` নির্বাচন করবে।

---

# Pseudo Class (`:`)

## ৯. `:hover`

```css
button:hover{
    background:red;
}
```

**মানে:** Mouse নিলে Style পরিবর্তন হবে।

---

## ১০. `:focus`

```css
input:focus{
    border:2px solid blue;
}
```

**মানে:** Input-এ Click করলে Style পরিবর্তন হবে।

---

## ১১. `:required`

```css
input:required{
    background:yellow;
}
```

**মানে:** Required Input নির্বাচন করবে।

---

## ১২. `:checked`

```css
input:checked{
    margin:20px;
}
```

**মানে:** Checked Checkbox/Radio নির্বাচন করবে।

---

# Child Selector

## ১৩. `:first-child`

```css
li:first-child{
    color:red;
}
```

**মানে:** প্রথম `li` নির্বাচন করবে।

---

## ১৪. `:last-child`

```css
li:last-child{
    color:blue;
}
```

**মানে:** শেষ `li` নির্বাচন করবে।

---

## ১৫. `:nth-child()`

```css
li:nth-child(2){
    color:green;
}
```

২ নম্বর Item নির্বাচন করবে।

```css
li:nth-child(2n){
    background:yellow;
}
```

সব Even Item নির্বাচন করবে।

```css
li:nth-child(2n+1){
    background:gray;
}
```

সব Odd Item নির্বাচন করবে।

---

## ১৬. `:not()`

```css
li:not(.active){
    color:red;
}
```

`active` Class বাদে সব `li` নির্বাচন করবে।

---

# Pseudo Element (`::`)

## ১৭. `::before`

```css
h1::before{
    content:"★ ";
}
```

**Output**

```
★ Welcome
```

Element-এর আগে Content যোগ করে।

---

## ১৮. `::after`

```css
h1::after{
    content:" ✔";
}
```

**Output**

```
Welcome ✔
```

Element-এর পরে Content যোগ করে।

---

# Attribute Selector

## ১৯. Attribute আছে

```css
[data-id]{
    color:red;
}
```

`data-id` Attribute থাকলে নির্বাচন করবে।

---

## ২০. নির্দিষ্ট Value

```css
[data-id="123"]{
    color:red;
}
```

শুধুমাত্র `123` হলে নির্বাচন করবে।

---

## ২১. `^=` (Starts With)

```css
[data-id^="12"]
```

`12` দিয়ে শুরু হলে।

Example:

```
1234 ✔
1256 ✔
4512 ✖
```

---

## ২২. `$=` (Ends With)

```css
[data-id$="34"]
```

`34` দিয়ে শেষ হলে।

Example:

```
1234 ✔
2234 ✔
3412 ✖
```

---

## ২৩. `*=` (Contains)

```css
[data-id*="23"]
```

যেখানে `23` থাকবে।

Example:

```
1234 ✔
4523 ✔
6789 ✖
```

---

# CSS Priority (Specificity)

```
Inline Style
      ↓
ID (#)
      ↓
Class (.)
      ↓
Element (div, p)
```

উপরেরটি যত উপরে থাকবে, তার Priority তত বেশি।

---

# মনে রাখার Shortcut

* `.` → Class (অনেক Element)
* `#` → ID (Unique)
* `>` → Direct Child
* ` ` (Space) → ভিতরের সব Child
* `+` → পরের প্রথম Element
* `~` → পরের সব Element
* `:` → Pseudo Class
* `::` → Pseudo Element
* `^=` → Starts With
* `$=` → Ends With
* `*=` → Contains
