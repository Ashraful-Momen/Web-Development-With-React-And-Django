Here is the exact code syntax for everyday operations on each data structure:

# =====================================================================# 1. LISTS [ mutable, ordered, allows duplicates ]# =====================================================================# CREATEmy_list = [10, 20, 30]
# READ / SEARCH
print(my_list[0])        # 👉 10 (Access by index)
print(20 in my_list)     # 👉 True (Search presence)idx = my_list.index(20)  # 👉 1 (Find index of item)
# UPDATE
my_list[0] = 99          # Modifies specific index -> [99, 20, 30]
my_list.append(40)       # Adds to the end -> [99, 20, 30, 40]
my_list.insert(1, 15)    # Inserts at index 1 -> [99, 15, 20, 30, 40]
# DELETE
my_list.pop()            # Removes and returns last item
my_list.remove(20)       # Removes first occurrence of value 20del my_list[0]           # Removes item at index 0
# DAILY OPERATIONS
my_list.reverse()        # Flips list order in place
my_list.sort()           # Sorts elements in placesize = len(my_list)      # Total elements count

# =====================================================================# 2. TUPLES ( immutable, ordered, allows duplicates )# =====================================================================# CREATEmy_tuple = (10, 20, 30, 20)
# READ / SEARCH
print(my_tuple[1])        # 👉 20 (Access by index)
print(30 in my_tuple)     # 👉 True (Search presence)count = my_tuple.count(20)# 👉 2 (Count occurrences)
# UPDATE / DELETE (The Golden Rule)# Tuples are immutable! You must cast to list first.tmp = list(my_tuple)      # Convert to List
tmp.append(40)            # Perform CRUD operationmy_tuple = tuple(tmp)     # Convert back to Tuple -> (10, 20, 30, 20, 40)
# DAILY OPERATIONSi1, *i2, i3 = my_tuple    # Unpacking via * operator

SETS { unique elements only, unordered, unindexed }# =====================================================================# CREATEmy_set = {10, 20, 30}empty_set = set()         # Crucial: {} creates an empty dict, not a set!

Here's a quick comparison table of Python's main data structures:

| Data Type | Mutable | Ordered | Indexed | Duplicates | Syntax |
|-----------|---------|---------|---------|------------|--------|
| **List** | ✅ Yes | ✅ Yes | ✅ Yes | ✅ Allowed | `[]` |
| **Tuple** | ❌ No | ✅ Yes | ✅ Yes | ✅ Allowed | `()` |
| **Set** | ✅ Yes | ❌ No | ❌ No | ❌ Not Allowed | `{}` |
| **Dictionary** | ✅ Yes | ✅ Yes* | ✅ By Key | ❌ Keys Unique | `{key: value}` |

**Key Points:**
- **List**: Ordered, mutable collection
- **Tuple**: Ordered, immutable collection  
- **Set**: Unordered, unique elements only
- **Dictionary**: Key-value pairs, keys must be unique

*\*Dictionaries maintain insertion order in Python 3.7+*
